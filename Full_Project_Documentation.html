🛠️ 2. Core Hiring Lifecycle (The Handshake)

This follows a strict multi-step confirmation process between Client and Worker.

sequenceDiagram participant C as Client App participant B as .NET Backend participant W as Worker App Note over C,W: Phase 1: Invitation C->>B: POST /BookInterview B->>W: GET /GetWorkerRequests Note over C,W: Phase 2: Worker Interest W->>B: PUT /UpdateWorkerDecision (Accept) B->>C: GET /GetActiveRequests (Worker Accepted) Note over C,W: Phase 3: Client Hiring C->>B: PUT /UpdateHiringStatus (Hire) B->>W: GET /GetWorkerJobConfirmations (You are Hired!) Note over C,W: Phase 4: Final Start W->>B: PUT /WorkerAcceptJobOffer C->>B: PUT /ClientConfirmWorkerAcceptance Note right of B: Status = "Finalized"

Screen-by-Screen Breakdown

Step Screen API Call Data Context
1 FindServiceScreen GET /GetWorkersForClient Search & Search results list.
2 WorkerDetailScreen GET /GetWorkerDetail/{id} Full profile, reviews, and current job status.
3 InterviewSelection POST /BookInterview Sets Status: Pending, HiringDecision: Pending.
4 ActiveRequests (W) PUT /UpdateWorkerDecision Worker chooses "Accept" or "Reject" for interview.
5 ActiveRequest (C) GET /GetActiveRequests Client sees if the worker is interested.
6 JobConfirmation (W) PUT /WorkerAcceptJobOffer Worker final "Yes" to start working.

🚪 3. Contract Termination & Feedback

How jobs are ended, either voluntarily (Resignation) or by the client (Termination).

Flow A: Worker Resignation

1
LeaveJobScreen: Worker submits ResignationReason and LastWorkingDate.
2
ResignationsScreen (C): Client views the list of incoming notices.
3
ResignationScreen (C): Client confirms the end of job and submits a Rating/Review.

Flow B: Client Termination

1
TerminateContractScreen: Client fires worker immediately.
2
Backend Logic: Status becomes Terminated, review is stored, and Termination record is created.

📱 4. Flutter Integration Checklist

For running the same project on another device.

  • Config: Ensure _ipAddress matches your PC's Wi-Fi IP (from ipconfig).
  • Android: Set android:usesCleartextTraffic="true" in Manifest.
  • iOS: Set NSAllowsArbitraryLoads to true in Info.plist.
  • Connection: Phone and PC must be on the same local network.
